# Захарыч — телеграм-демон

Автономный «Игорь Захарыч»: Telegram-бот с личностью из AGENTS.md и памятью из `memory/`.
Живёт на компе Космоса (пока комп включён), пинает по расписанию, отвечает как живой.

## Архитектура

```
Telegram ←→ daemon.py (polling + планировщик) ←→ pi --print --session-id zaharych-tg
                                                    ↑ cwd = ~/Documents/ai
                                                    (AGENTS.md = личность, memory/ = память)
```

- **Личность и память** — pi грузит `AGENTS.md` и `memory/` из рабочей папки.
- **Сессия** — именная `zaharych-tg`: контекст помнится между сообщениями, отдельная от твоих интерактивных сессий.
- **Токен-экономия**: пинания по расписанию — шаблонные (0 токенов), живой мозг включается только на твои сообщения и утренний бриф.

## Запуск (первый раз)

1. **Создай бота**: в Telegram у @BotFather → `/newbot` → имя (напр. «Игорь Захарыч»), username.
   Получишь токен вида `123456:AA...`.
2. **Секреты**:
   ```bash
   cd zaharych
   cp .env.example .env
   nano .env   # вставь TG_BOT_TOKEN
   ```
   `.env` и `chat.id` в `.gitignore` — доступы не утекут.
3. **Зависимости** (в виртуалке):
   ```bash
   python3 -m venv .venv
   source .venv/bin/activate
   pip install -r requirements.txt
   ```
4. **Пуск**:
   ```bash
   python3 src/daemon.py
   ```
5. Напиши боту любое сообщение — он запомнит твой chat_id (файл `chat.id`) и с этого момента ты единственный, с кем он говорит.

## Регламент касаний

| Время | Что | Мозг |
|-------|-----|------|
| 07:00 | Утренний бриф (цели из memory/04_goals + упражнения) | LLM |
| 12:00 | Дневной пинок | шаблон |
| 21:30 | «Ложись, брат» | шаблон |
| Ты пишешь | Живой ответ с памятью | LLM |

## Расширение (фаза 2+)

- Google Calendar: чтение встреч утром → в бриф.
- Крипто-алерты: контроль позиций (урок Compound).
- Задачник: «ты обещал — где результат?»
- systemd-юнит для автозапуска (см. README позже).

## Логи

`logs/daemon.log` — всё, что демон делает. Если бот молчит — смотри туда.

## Картинки

Пришли боту фото или файл-картинку (график, скриншот) — файл ляжет в `inbox/`,
уйдёт в зрение агента и через сутки приберётся автоматически. Подпись к
картинке считается текстом сообщения — можно сразу задать вопрос по картинке.

## Язык

Все плановые тексты, промпты и служебные ответы лежат в файлах локализации:

```
src/locales/en.py   # английский
src/locales/ru.py   # русский (по умолчанию)
```

Выбор — `ZAHARYCH_LANG=en|ru` в `.env`. Команды: `/ping`,
`/напомни ЧЧ:ММ текст` (`/remind` в en-локали), `/напоминания`.
